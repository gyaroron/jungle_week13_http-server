# 학습자 이해·학습 진행 분석 기록

## 목적

이 문서는 C 웹서버·프록시 튜토리얼에서 학습자가 실제로 답한 내용을 근거로, 설명의 난이도와 형태를 조정하기 위한 기록입니다. 능력이나 성격을 진단하지 않습니다. 기록된 답변에서 확인된 이해와 아직 확인되지 않은 항목을 구분합니다.

## 분석 원칙

- 학습자의 답변을 근거로 삼고, 관찰한 답변이나 대화 맥락을 가능한 한 짧게 인용하거나 요약합니다.
- 한 번의 답변만으로 고정된 능력이라고 판단하지 않습니다. 같은 개념을 다른 문맥에서도 적용했는지 확인합니다.
- `확인됨`, `힌트 뒤 확인됨`, `아직 확인되지 않음`을 구분합니다. 답이 틀렸다는 사실만 적지 않고, 어떤 설명 뒤에 생각이 어떻게 바뀌었는지도 기록합니다.
- 문장구사력·어휘 수준은 기술 지식과 섞지 않습니다. 짧은 질문이나 오타만으로 일반적인 한국어 능력을 평가하지 않습니다.
- 답변 간격을 학습에 쓴 시간으로 간주하지 않습니다. 사용자가 자리를 비웠거나 다른 일을 했을 수 있기 때문입니다.
- 분석 결과는 다음 설명의 길이, 어휘, 시각화, 질문 난이도를 조정하는 데만 사용합니다.

## 관찰 수준

| 수준 | 의미 |
|---|---|
| 독립 설명 | 별도 힌트 없이 핵심 관계와 이유를 자신의 말로 설명함 |
| 적용 확인 | 설명을 들은 뒤 새 사례에 핵심 개념을 적용함 |
| 힌트 뒤 확인 | 한 번 이상의 구체적 설명이나 시각화 뒤 핵심을 다시 설명함 |
| 추가 설명 필요 | 답변에서 핵심 관계가 아직 혼동되거나 잘못 연결됨 |
| 자료 부족 | 해당 능력을 판단할 답변이 아직 없음 |

이 구분은 해당 구간의 관찰 기록이지, 학습자에 대한 고정 등급이 아닙니다.

## 시간당 학습량 측정 기준

- 한 학습 구간의 시작·종료 시각, 다룬 핵심 항목 수, 독립 설명으로 확인된 항목 수, 필요했던 설명·힌트 횟수를 기록합니다.
- 실제 집중 학습 시간이 확인되면 `확인된 핵심 항목 수 ÷ 집중 학습 시간(시간)`을 사용합니다.
- 집중 시간이 없더라도 사용자가 요청한 경우, 설명 제시부터 답변 확인까지의 대화 경과 시간으로 `답변에서 확인된 핵심 항목 수 ÷ 경과 시간(시간)`을 별도 잠정 지표로 계산합니다. 이 값은 집중 학습 시간이나 장기 학습 능력으로 부르지 않습니다.
- 잠정 지표에는 답변 수준(독립 설명·적용·설명 뒤 회상), 문항 수, 대략적 시각 범위를 함께 적고, 한두 문항만으로 일반화하지 않습니다. 서로 다른 난이도를 섞어 비교하지 않습니다.
- 응답이 빠르다는 사실만으로 이해를 판정하지 않습니다. 핵심 관계를 정확히 설명하거나 새 상황에 적용한 답변을 확인 항목으로 셉니다.

### 현재 설명 방식의 임시 조정

- 새 용어는 영어 원문과 한글 뜻을 함께 제시하고, 바로 뒤에 쉬운 뜻을 설명합니다.
- 설명은 “누가, 누구에게, 어떤 값을, 어떤 동작으로 전달하거나 바꾸는가” 순서로 씁니다.
- 포트 번호와 파일 서술자처럼 숫자로 보이지만 역할이 다른 값을 한 그림에서 구분합니다.
- 작은 문법 확인보다 전체 요청 흐름에서 중요한 관계를 먼저 설명합니다.
- 정답을 유도하는 질문을 연속으로 하기보다, 핵심을 먼저 설명한 뒤 필요한 경우에만 큰 개념을 확인합니다.

## 2026-11-25 13:19 KST — TCP 상태와 프로그램 처리 상태 구분

- 관찰 근거: 사용자는 “ESTABLISHED는 client와 server가 연결이 된 상태를 알리는 것이며, CONN_READING은 server program이 요청을 읽는 중이라는 상태”라고 답했습니다.
- 개념 이해: 앞선 쉬운 설명 뒤 두 상태의 뜻을 올바르게 구분했습니다. `ESTABLISHED`는 TCP 연결 상태이고 `CONN_READING`은 서버 프로그램의 요청 처리 상태입니다. 이번 관찰은 `힌트 뒤 확인`으로 기록합니다.
- 남은 확인: 답변에서 `ESTABLISHED`를 관리하는 주체가 커널이라고 명시하지 않았습니다. 연결 종료 상태와 `CONN_CLOSING`의 관계, 연결 유지 시 다시 읽기로 돌아가는 흐름도 아직 확인되지 않았습니다.
- 문장·어휘: 답변의 뜻은 분명합니다. 마지막 글자 오타 하나로 문장구사력이나 어휘 수준을 평가하지 않습니다.
- 학습 속도: 메시지 사이의 경과 시간을 집중 학습 시간으로 볼 수 없어 시간당 학습량은 측정하지 않습니다.
- 다음 조정: 두 상태의 관리 주체를 한 번 더 분명히 짚고, 종료·유지 두 경로를 짧은 흐름으로 연결합니다.
