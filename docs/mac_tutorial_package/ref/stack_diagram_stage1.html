C 웹서버 · 프록시 만들기 — 1단계

요청 한 개가 클라이언트에서 프록시 서버를 거쳐 백엔드까지 갔다가 돌아오는 전체 HTTP 메시지 흐름과, 그동안 서버 쪽 소켓이 거치는 TCP 상태 머신입니다. 카드의 문장 · 화살표 · 상태를 누르면 가운데 창에서 근거 줄과 해석을 볼 수 있습니다.

이 지도의 근거와 한계

  • 구현 소스 코드는 아직 없습니다. 그래서 모든 창의 “확인” 칸과 발췌는 작업 범위로 정한 두 md 파일의 실제 줄 번호와 그 줄의 원문입니다. 지어낸 C 코드를 원본처럼 싣지 않았습니다.
  • 근거 파일 1: C 웹서버 · 프록시 구현 요구사항 라인 바이 라인 정밀 해석 — … 24개 항목.md (요구사항 파일)
  • 근거 파일 2: C 웹서버_AI 함께하기 가이드 라인 바이 라인 정밀 해석 — … 31개 항목.md (가이드 파일)
  • 실행 환경은 macOS를 전제로 합니다. 창에 적힌 확인 명령(netstat -an -p tcp, lsof, sysctl)은 macOS에 있는 명령입니다. Linux 전용인 ss · epoll · accept4는 쓰지 않습니다.
  • “예상” 칸은 설계로 기대하는 결과이고, 아직 실행해서 잰 값이 아닙니다. 이 파일에는 측정 수치가 하나도 없습니다.

얇은 회색 선 ① ~ ⑦은 항상 보입니다. 시나리오와 단계를 고르면 지금 단계의 선이나 카드가 굵은 색으로 강조되고, 분홍 글자는 그 단계에서 불리는 함수입니다.
