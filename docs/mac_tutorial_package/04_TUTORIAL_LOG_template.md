# 튜토리얼 진행 기록

이 파일을 `docs/TUTORIAL_LOG.md`로 복사해 씁니다. 구간 하나가 끝날 때마다 아래 "구간 기록 양식"을 복사해 채웁니다.

적는 규칙:

- 사용자가 실제로 한 말과, 터미널에 실제로 나온 출력만 적습니다.
- 대본의 기대 결과와 실제 출력이 다르면 실제 출력을 적고 "다름"이라고 표시합니다.
- 하지 않은 실험은 "하지 않음"과 이유를 적습니다.
- 재지 않은 숫자를 적지 않습니다.
