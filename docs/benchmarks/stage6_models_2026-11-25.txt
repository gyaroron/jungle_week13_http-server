# ApacheBench — 동시성 모델 비교 원문

- 날짜: 2026-11-25 KST
- 도구: ApacheBench 2.3
- 프로젝트: macOS C 웹서버·프록시, `make clean && make`로 각 브랜치를 다시 빌드
- 컴파일 옵션: `-std=c11 -Wall -Wextra -Wpedantic -g -O0 -Iinclude -pthread`
- 요청: 정적 파일 `/` (169 bytes), 요청 2,000개, 동시성 50, keep-alive 옵션 없음
- 서버: `127.0.0.1:18080`; 클라이언트와 서버는 같은 Mac에서 실행
- 서버 표준 오류는 모든 모델에서 `/dev/null`로 보냈습니다. 로그 출력이 처리량을 달리하는 영향을 줄이기 위한 동일 조건입니다.
- 모델마다 4회 측정했습니다. 각 출력의 실패 요청 수는 0입니다. 비교 요약은 4회 중앙값과 범위를 씁니다.
- 각 서버를 띄운 뒤 연결 준비 여부를 확인하는 TCP 접속 한 번을 실행했습니다. 이 준비 확인은 ApacheBench의 2,000건에는 포함되지 않습니다.

## 비교 해석의 범위

`stage6-sequential`은 현재 프로젝트의 HTTP·정적 파일 모듈을 유지하고 `accept()` 뒤 `conn_handle()`을 `main` 스레드에서 동기 호출하는 기준 모델입니다. 튜토리얼이 지정한 1단계 과거 커밋의 원본 서버 코드는 현재 Git 이력에 없었습니다. 따라서 세 모델의 처리 경로를 맞추기 위해 과거 서버 전체를 복원하지 않고 연결 분배 방식만 바꿨습니다. 이 차이는 측정 결과를 읽을 때 고려해야 합니다.

## 표준 조건 전 1차 실행 — 비교표에서 제외

초기 실행은 서버 로그를 도구 출력 또는 파일로 보냈습니다. 표준 측정은 세 모델 모두 `/dev/null`로 통일했으므로, 초기 처리량은 비교 중앙값에 포함하지 않습니다. 실패 요청은 모두 0이었습니다.

| 모델 | 예비 실행의 초당 요청 수 |
|---|---|
| 순차 처리 | 5,044.85; 6,831.65; 6,662.16; 12,600.73 |
| 연결별 스레드 | 10,931.23; 10,145.54; 9,829.94; 10,043.39 |
| 스레드 풀 (`-w 8`) | 11,826.55; 11,712.00; 11,018.62; 11,142.00 |
